#DESCRIPTION

Expense Tracker is a Python-based application that helps users record, manage, and analyze daily expenses. It supports adding, viewing, and deleting expenses while storing data persistently using CSV or JSON files. The system also provides category-wise spending breakdown and total expense summary, making personal budget tracking simple and efficient.
